# Support

Compute Relay is pre-release and currently contains project documentation and repository policy rather than a usable runtime.

Use GitHub Issues for reproducible documentation defects, implementation bugs, or focused feature proposals. Search existing issues first and include the expected behavior, actual behavior, relevant commit, platform, sanitized diagnostics, and whether external provider calls were involved.

Do not use a public issue for vulnerabilities, credentials, private provider data, or conduct incidents. Follow [`SECURITY.md`](SECURITY.md) or [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) instead.

The project does not provide provider-account support, quota guarantees, legal advice, or a service-level agreement. Operators remain responsible for their own accounts, credentials, workloads, data rights, and compliance with provider terms.
